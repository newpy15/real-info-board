# real-info-board

> 7일 USD·JPY·KRW 환율 비교와 **원자료·저장값·화면값 3계층 정합성 검증**을 한 화면에 담은 단일 HTML 대시보드.
> 빌드·서버·의존성 없음. `index.html` 하나로 동작합니다.

## 미리보기

- 7일 환율 비교표 (USD/KRW, JPY(100)/KRW, USD/JPY 교차 환율, 전일 대비)
- 7일 요약 (최고·최저·7일 변동)
- 7일 스파크라인 (▁▂▃▄▅▆▇█)
- 3계층 대조 (원자료 → 저장값 → 화면값, 숫자 정규화 후 의미값 비교)
- stale 재현 및 불일치 주입 데모

## 사용 방법

1. 저장소를 클론하거나 `index.html`을 내려받습니다.
2. `index.html`을 브라우저로 엽니다. (더블클릭 또는 `file://` 경로)
3. **"7일 데이터 불러오기"** 버튼을 누릅니다.
   - 7일 비교표, 7일 요약, 스파크라인이 채워집니다.
   - 3계층 대조 섹션은 **접힌 상태**로 데이터만 채워집니다.
4. 접힌 **"📋 원자료 · 저장값 · 화면값 대조 (7일)"** 헤더를 클릭하면 펼쳐집니다.
   - 접힌 상태에서도 헤더 우측에 `14/14건 일치` 와 `전건 일치` 배지가 보입니다.
5. 필요 시 아래 버튼을 사용합니다.

| 버튼 | 동작 |
|---|---|
| **7일 데이터 불러오기** | 7일치 합성 데이터를 새로 생성해 표·요약·스파크라인·3계층 대조를 채움 |
| **중간 하루 실패 재현 (stale)** | 4번째 날을 stale 상태로 바꾸고, 직전 정상값을 유지한 채 표시 |
| **7일 비교표 고정 (증거)** | 현재 데이터를 스냅샷으로 고정하고 3계층 대조를 펼침 |
| **불일치 1건 주입 (데모)** | 4번째 날 USD/KRW 화면값에 +1을 더한 것처럼 만들어 `불일치` 배지가 실제로 뜨는지 확인 |
| **자동 펼침** 체크박스 | 체크하면 데이터 로드 시 3계층 대조가 자동으로 펼쳐짐 (기본 꺼짐) |

### 3계층 대조 읽는 법

각 통화쌍마다 아래 3줄이 표시됩니다.

- **원자료**: 소스가 준 원본 **문자열** 그대로 (예: `"1338.50"`)
- **저장값**: `JSON.stringify` → `JSON.parse` 왕복 + `Number()` 타입 변환 (예: `1338.5`)
- **화면값**: `Intl.NumberFormat` 포맷 → DOM 렌더 → `textContent`로 **다시 읽은 문자열** (예: `"1,338.50"`)

표현은 세 가지로 달라도, `normalizeNum()`으로 쉼표 제거·소수 2자리 반올림 후 비교하면 **의미값이 일치**해야 합니다. 불일치가 뜨면 저장·포맷·시각대 변환 중 어딘가에서 값이 변조됐다는 신호입니다.

## 데이터에 대해

- 현재 코드는 **합성 데이터**를 사용합니다 (`generate7Days()`).
- 실제 운영 시 한국은행 ECOS API의 `usd_krw`(원/달러 종가), `jpy_krw`(원/100엔 종가)를 7영업일 범위로 조회해 교체하면 됩니다.
- **API 키는 서버측 환경변수로만** 두고, 브라우저에 노출하지 마세요.
- 주말·공휴일은 직전 영업일 값을 유지하는 처리가 필요합니다.
- `generate7Days()` 내부만 실응답으로 바꾸면 나머지 로직(요약·스파크라인·3계층 검증)은 그대로 동작합니다.
